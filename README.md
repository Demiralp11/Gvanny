# Granny’den Kaç — Render kurulumu

Klasör yapısı:
```
server.js
package.json
public/index.html
```

1. Bu 3 dosyayı GitHub reposuna koy (gvanny servisinin bağlı olduğu repo).
2. Render’da servis ayarları: **Build Command** `npm install`, **Start Command** `node server.js`.
3. Deploy bitince https://gvanny.onrender.com/ açılır. Menüden **ODA KUR**, çıkan kodu arkadaşlara ver, onlar **KATIL**’a basıp kodu girer.

Notlar: Ücretsiz Render planı boşta kalınca uyur, ilk açılış ~30 sn sürebilir. Oda başına en fazla 8 oyuncu.
